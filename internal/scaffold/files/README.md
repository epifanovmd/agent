# Агент

Папка агента: программа, её настройки и воркеры. Всё, что агент делает на этой машине и на узлах,
описано здесь.

| Что                                 | Зачем                                                       |
| ----------------------------------- | ----------------------------------------------------------- |
| `agent`                             | программа агента (в git не хранится, см. ниже)              |
| `agent.yaml`                        | настройки для этой машины — `./agent run` читает его сам    |
| `agent.prod.yaml`                   | боевые узлы: поверх `agent.yaml`, воркеры те же             |
| `.env`, `.env.prod`                 | адрес бэкенда, токен регистрации, ключи (в git не хранятся) |
| `.env.example`, `.env.prod.example` | образцы для них                                             |
| `workers/`                          | воркеры: каждый — папка с исполняемым `run`                 |
| `.data/`                            | данные агента на этой машине (в git не хранятся)            |

## Команды

```bash
./agent worker new report     # новый воркер из заготовки (--lang python|go)
./agent worker list            # воркеры: откуда каждый, версия
./agent run                    # запустить на этой машине (Ctrl+C — остановить)
./agent config check           # что получилось из настроек и откуда каждое значение
./agent status                 # работает ли агент, связь, воркеры
./agent run --env prod         # то же с настройками боевых узлов
./agent pack --env prod        # архив для узла: программа, настройки, воркеры
sudo ./agent install --env prod   # на узле, из распакованного архива: агент — службой
./agent upgrade                # поставить новую версию агента
```

## Программы нет

Программа агента в git не хранится. После `git clone` её скачивают один раз:

```bash
curl -fLo agent "https://github.com/epifanovmd/agent/releases/latest/download/agent-$(uname -s | tr A-Z a-z)-$(uname -m | sed 's/x86_64/amd64/;s/aarch64/arm64/')"
chmod +x agent
```

Дальше новые версии ставит `./agent upgrade`.
