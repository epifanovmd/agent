# Воркеры

Воркер — небольшой сервис на любом языке, который делает работу на узле. Новый воркер из
заготовки — `../agent worker new <имя> [--lang python|go]`: папка с базой `agent_worker.py` или `agent_worker.go`
(протокол агента: здоровье, манифест, настройки, задачи, события — не правьте её, её обновляет
`agent worker sync`) и файлом воркера с классом-наследником базы — там только ваш код. Строку в
`agent.yaml` команда добавит сама.

Каждый воркер — папка:

- `run` — исполняемый файл, который запускает воркер (`#!/bin/sh` и `exec …`);
- `VERSION` — версия воркера.

Агент запускает `./run` в папке воркера и передаёт ему в окружении `AGENT_WORKER_SOCKET`: на этом
unix-сокете воркер отвечает по HTTP. Обязательно — `GET /health` и `GET /manifest`; что ещё может
воркер, — https://github.com/epifanovmd/agent/blob/main/sdk/docs/workers.md

Подключить воркер — строка в `../agent.yaml`:

```yaml
workers:
  - path: workers/<имя>
```
